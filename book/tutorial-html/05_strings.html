Tutorial 5: Strings

Source file: tutorials/05_strings.jts — a complete, runnable program. Every tutorial in this book is a file in the repository's tutorials/ folder.

Goal: Slice, search, and transform text.

Strings have methods: upper(), lower(), trim(), contains(s),

replace(a, b), substring(s, e), starts_with(s), split(sep), join(list).

The strings scroll adds more helpers.

greeting = "  Hello, JTS GO!  "
say("trimmed: [" + greeting.trim() + "]")
say("upper: " + greeting.upper())
say("lower: " + greeting.lower())
say("contains 'JTS': " + str(greeting.contains("JTS")))
say("starts with 'Hi': " + str(greeting.starts_with("Hi")))
say("replaced: " + greeting.replace("JTS", "World"))

text = "a,b,c,d"
parts = text.split(",")
say("split: " + str(parts))
say("joined: " + "-".join(parts))
say("length: " + str(len(text)))
