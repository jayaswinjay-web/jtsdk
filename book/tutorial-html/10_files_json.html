Tutorial 10: Files and JSON

Source file: tutorials/10_files_json.jts — a complete, runnable program. Every tutorial in this book is a file in the repository's tutorials/ folder.

Goal: Read and write files, and work with JSON data.

Built-ins: write_file(path, text), read_file(path).

The json scroll adds parse/stringify, the fs scroll adds file helpers.

write_file("_tutorial_notes.txt", "line one\nline two\nline three\n")
content = read_file("_tutorial_notes.txt")
say("read back:")
say(content)

bring fs
say("fs.exists: " + str(fs.exists("_tutorial_notes.txt")))
say("line count: " + str(fs.count_lines("_tutorial_notes.txt")))
say("first line: " + fs.first_line("_tutorial_notes.txt"))
say("last line: " + fs.last_line("_tutorial_notes.txt"))

bring json
data = json.parse('{"name": "JTS GO", "version": 1, "features": ["easy", "fast"]}')
say("name: " + data["name"])
say("version: " + str(data["version"]))
say("first feature: " + data["features"][0])
say("stringify: " + json.stringify({"a": 1, "b": [2, 3]}))

json.save("_tutorial_data.json", {"app": "demo", "count": 3})
loaded = json.load("_tutorial_data.json")
say("loaded app: " + loaded["app"])
say("loaded count: " + str(loaded["count"]))
say("pretty:")
say(json.pretty(loaded))
