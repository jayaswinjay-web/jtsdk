Tutorial 7: Lists

Source file: tutorials/07_lists.jts — a complete, runnable program. Every tutorial in this book is a file in the repository's tutorials/ folder.

Goal: Store many values and transform them.

Indexing starts at 0: items[0]. Append with append(list, v) or list.append(v).

Iterate with for x of items. Built-ins: len(), sort(), pop(), reverse().

fruits = ["apple", "banana", "cherry"]
say("first: " + fruits[0])
say("last: " + fruits[2])
say("length: " + str(len(fruits)))

fruits.append("date")
say("after append: " + str(fruits))
fruits.pop()
say("after pop: " + str(fruits))

numbers = [5, 3, 9, 1, 7]
numbers.sort()
say("sorted: " + str(numbers))

total = 0
for n of numbers
    total = total + n
end
say("sum: " + str(total))
