How to Use This Book

This is the hands-on companion to The JTS GO Programming Language. Where the reference book explains the language topic by topic, this book teaches it the way most people actually learn: by running real programs.

There are twelve tutorials, one per chapter, and they build on each other like a ladder. Tutorial 1 is a three-line “Hello, World!” program; by Tutorial 12 you will have touched machine learning and web servers. Each chapter presents one complete, runnable program together with a short explanation and a Challenge at the end. Do not skip the challenges — they are the whole point of a learn-by-doing book.

Every tutorial is also a file in the repository's tutorials/ folder. If you installed JTS GO through npm, the folder is already on your machine inside the installation directory. Run any tutorial from any folder:

jts tutorials/01_hello.jts

The scrolls some tutorials use (math, strings, lists, sets, json, fs) resolve automatically no matter which folder you are in, so you can run every example exactly as printed.
