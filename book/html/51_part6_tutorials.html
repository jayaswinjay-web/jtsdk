43. Learn by Doing: The 12 Tutorials

This chapter is a hands-on recap of the whole book. Twelve short programs walk you through the language from your first say to machine learning and web servers. Every program is a complete, runnable file in the repository's tutorials/ folder:

jts tutorials/01_hello.jts

The scrolls used by some tutorials (math, strings, lists, sets, json, fs) resolve from any working directory, so you can run a tutorial from anywhere. Each section ends with a Challenge for you to try before moving on.

43.1 Hello, World!

The very first program. say prints a value to the console (Chapter 14).

say("Hello, World!")
say("Welcome to the JTS GO tutorial!")

Challenge: change the greeting to your own name.

43.2 Variables and Math

JTS GO is dynamically typed: x = 42 needs no type keyword. Arithmetic uses + - * / %, and str() converts numbers for string concatenation (Chapters 5, 6, and 7).

name = "Alex"
age = 7
say("Hi, " + name + "!")
say("In 3 years you will be " + str(age + 3))

pi = 3.14159
say("Pi doubled: " + str(pi * 2))
say("Remainder of 17 / 5: " + str(17 % 5))

Challenge: compute and print the area of a circle with radius 4.

43.3 Conditionals

Decision-making with if / elif / else, comparisons, the logical operators and / or / not, and the of membership test (Chapter 8).

score = 85
if score >= 90
    say("Grade: A")
elif score >= 80
    say("Grade: B")
elif score >= 70
    say("Grade: C")
else
    say("Grade: F")
end

x = 7
if x > 0 and x % 2 == 0
    say("positive and even")
elif x > 0
    say("positive and odd")
end

primes = {2, 3, 5, 7}
if 7 of primes
    say("7 is prime")
end

43.4 Loops

Note that for i of 0 to 10 is inclusive: it visits 0, 1, ..., 10. Lists iterate with for x of items, and break / continue control the flow (Chapter 8).

for i of 1 to 5
    say("Counting: " + str(i))
end

items = ["apple", "banana", "cherry"]
for fruit of items
    say("I like " + fruit)
end

n = 0
while n < 3
    n = n + 1
    if n == 2
        continue
    end
    say("while n = " + str(n))
end

for i of 1 to 10
    if i == 4
        break
    end
    say("until break: " + str(i))
end

Challenge: print the first 5 even numbers using a loop.

Strings expose methods such as upper(), trim(), contains(), replace(), split(), and join() (Chapters 12 and 16). The strings scroll adds more helpers (Chapter 27).

greeting = "  Hello, JTS GO!  "

say("contains 'JTS': " + str(greeting.contains("JTS")))

text = "a,b,c,d"
parts = text.split(",")
say("split: " + str(parts))

43.6 Functions

Functions group reusable code with func, parameters, return, and recursion (Chapter 9). A function without return returns void.

func greet(name)
    say("Hello, " + name + "!")
end

func add(a, b)
    return a + b
end

func is_even(n)
    if n % 2 == 0
        return true
    end
    return false
end

func factorial(n)
    if n <= 1
        return 1
    end
    return n * factorial(n - 1)
end

greet("Alex")
say("add(3, 4) = " + str(add(3, 4)))
say("is_even(10) = " + str(is_even(10)))
say("factorial(5) = " + str(factorial(5)))

func square(x)
    return x * x
end

func sum_of_squares(a, b)
    return square(a) + square(b)
end

say("sum_of_squares(3, 4) = " + str(sum_of_squares(3, 4)))

Challenge: write a function that counts down from n to 1.

43.8 Dictionaries and Sets

Dicts map string keys to values; sets hold unique values. Sets support |, &, and - operators and membership with of (Chapter 11). Dicts update with d.update({...}) (Chapter 18).

person = {"name": "Alex", "age": 7, "city": "Madurai"}
say("name: " + person["name"])
say("age: " + str(person["age"]))
person.update({"hobby": "coding"})
say("has hobby: " + str("hobby" of person))
say("keys: " + str(person.keys()))
say("get city: " + person.get("city"))
say("length: " + str(len(person)))

for key of person
    say("  " + key + " = " + str(person[key]))
end

primes = {2, 3, 5, 7, 11}
say("7 in primes: " + str(7 of primes))
say("set size: " + str(len(primes)))

a = {1, 2, 3, 4}
b = {3, 4, 5}
say("a | b = " + str(list(a | b)))
say("a & b = " + str(list(a & b)))
say("a - b = " + str(list(a - b)))

bring sets
say("union: " + str(list(sets.union(a, b))))
say("is subset: " + str(sets.is_subset({1, 2}, a)))

Challenge: count how many unique letters are in your name using a set.

43.9 Classes and Inheritance

OOP with class, constructors init(self, ...), self, new, and inheritance via extends. Inside a subclass method, super reaches the parent (Chapter 10).

class Animal
    func init(self, name)
        self.name = name
    end

    func speak(self)
        say(self.name + " makes a sound")
    end
end

class Dog extends Animal
    func speak(self)
        super.speak(self)
        say(self.name + " barks!")
    end
end

class Puppy extends Dog
    func init(self, name)
        super.init(self, name)
        self.cute = true
    end

    func speak(self)
        super.speak(self)
        say("So cute!")
    end
end

a = new Animal("Generic")
a.speak()

d = new Dog("Rex")
d.speak()

p = new Puppy("Milo")
p.speak()
say("Milo is cute: " + str(p.cute))

Challenge: add a Cat class with its own speak() and try it out.

43.10 Files and JSON

The built-ins write_file() / read_file() handle text files (Chapter 20). The json scroll parses, stringifies, loads, and saves JSON (Chapter 21), and the fs scroll adds file helpers (Chapter 33).

write_file("_tutorial_notes.txt", "line one\nline two\nline three\n")
content = read_file("_tutorial_notes.txt")
say(content)

bring fs
say("fs.exists: " + str(fs.exists("_tutorial_notes.txt")))
say("line count: " + str(fs.count_lines("_tutorial_notes.txt")))
say("first line: " + fs.first_line("_tutorial_notes.txt"))
say("last line: " + fs.last_line("_tutorial_notes.txt"))

bring json
data = json.parse('{"name": "JTS GO", "version": 1, "features": ["easy", "fast"]}')
say("name: " + data["name"])
say("first feature: " + data["features"][0])
say("stringify: " + json.stringify({"a": 1, "b": [2, 3]}))

json.save("_tutorial_data.json", {"app": "demo", "count": 3})
loaded = json.load("_tutorial_data.json")
say("loaded app: " + loaded["app"])
say("pretty:")
say(json.pretty(loaded))

The scratch files created here (_tutorial_notes.txt, _tutorial_data.json) are gitignored.

43.11 Errors

throw "message" raises an error; try / catch / finally handle it (Chapter 13). Explicit throw calls are catchable; low-level runtime failures stop the program.

func divide(a, b)
    if b == 0
        throw "cannot divide by zero"
    end
    return a / b
end

func require_positive(n)
    if n <= 0
        throw "expected a positive number, got " + str(n)
    end
    return n
end

try
    result = divide(10, 0)
    say("result: " + str(result))
catch err
    say("caught: " + err)
finally
    say("cleanup always runs")
end

say("still running after the error")

try
    say("10 / 2 = " + str(divide(10, 2)))
catch err
    say("should not reach here")
end

try
    require_positive(-3)
    say("never printed")
catch err
    say("caught: " + err)
end

Challenge: wrap an ask() in try/catch to reject empty input.

43.12 Machine Learning and Web

JTS GO ships ML built-ins — seed(), rand(), sigmoid(), mse(), matrix(), matmul() — and a built-in HTTP server: http_server(), http_route(), and http_start() (Chapters 23, 24, 40, and 41). Registering routes does not block; http_start(srv) serves until stopped.

seed(42)
say("sigmoid(0) = " + str(sigmoid(0)))
say("sigmoid(2) = " + str(sigmoid(2)))

actual = [0, 0, 1, 1]
predicted = [0.1, 0.4, 0.8, 0.9]
say("mse = " + str(mse(predicted, actual)))

a = matrix([[1, 2], [3, 4]])
b = matrix([[5, 6], [7, 8]])
say("matmul = " + str(matmul(a, b)))

say("randint(1, 6) = " + str(randint(1, 6)))

srv = http_server(8080)
http_route(srv, "GET", "/", "<h1>Hello from JTS GO</h1>")
http_route(srv, "GET", "/api/time", '{"now": 2026}')
say("server on port 8080 with 2 routes registered")
say("call http_start(srv) to serve")

Challenge: train sigmoid on [0,1] -> 0 and [1,0] -> 1, then print mse.
