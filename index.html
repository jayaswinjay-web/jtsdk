Features

Everything you need.
Nothing you don't.

Designed for absolute beginners, powerful enough for real projects.

[]

Lists, Dicts & Sets

First-class collections with [1, 2, 3], {"key": "value"}, and {1, 2, 3} — plus Python-style set union, intersection, and difference.

fn

Closures & Functions

First-class functions with recursion and closures. Nested functions capture their surrounding scope automatically.

>_

Bitwise Operators

&, |, ^, ~, <<, >> with compound assignments. Plus is, del, and assert.

oo

Object-Oriented

Classes, methods, and inheritance with extends and self. Clean, Python-like OOP out of the box.

ML

ML/AI Built-ins

Tensors, matrices, matmul, sigmoid, relu, and MSE loss — built directly into the language, no imports needed.

web

Web Development

Spin up an HTTP server with http_server(), serve pages, and make requests with http_request().

try

Errors, Handled

List comprehensions, try / catch / finally / throw, and graceful error handling built in.

pkg

Scrolls (Packages)

Reusable library files loaded with bring. A growing standard library ships with the kit.

dbg

VS Code Debugger

Full debugging support with breakpoints, step in/out/over, locals & globals — all inside VS Code.

Language

Clean, minimal, readable.

If you know Python, you already know most of JTS GO. Blocks close with end, everything is an expression, and the standard library covers everyday tasks.

Quick Start

Up and running in seconds.

One command. No build tools. No configuration.

1

Install Node.js

JTS GO installs through npm. If you don't have Node.js yet, grab it from the official site.

Download Node.js
2

Install JTS GO

One global npm install gives you the compiler, the VM, and the toolchain.

$ npm install -g @jaytechsolutions/jts-go copy
3

Run Your Code

Create a .jts file and run it instantly.

$ jts hello.jts copy
Toolchain

Three commands, every stage.

From source to bytecode to execution — all in your terminal.

jts

Compile and run a .jts file in one step

jtsc

Compile source to .jbc bytecode

jtsvm

Execute compiled bytecode directly

--update

Update to the latest version via npm
