# demo.jts — your first program
func fib(n)
    if n <= 1
        return n
    end
    return fib(n - 1) + fib(n - 2)
end

for i in 0 to 10
    print(fib(i))
end
Features

Everything you need. Nothing you don't.

Designed for absolute beginners, powerful enough for real projects.

Lists, Dicts & Sets

First-class collections with [1, 2, 3], {"key": "value"}, and {1, 2, 3} — with set union, intersection, and difference.

Closures & Functions

First-class functions with recursion and closures. Nested functions capture their surrounding scope.

Bitwise Operators

&, |, ^, ~, <<, >> with compound assignments. Plus is, del, and assert.

Classes & Inheritance

Classes, methods, and inheritance with extends and self. Clean OOP out of the box.

Machine Learning Built-ins

Tensors, matrices, matmul, sigmoid, relu, and MSE loss — built directly into the language.

HTTP Server

Spin up an HTTP server with http_server() and make requests with http_request().

Try, Catch, Finally

List comprehensions, try / catch / finally / throw, and graceful error handling.

Scrolls

Reusable library files loaded with bring. A standard library ships with the kit.

VS Code Debugger

Breakpoints, step in/out/over, and variable inspection inside VS Code.

Language

Clean, minimal, readable

Blocks close with end, everything is an expression, and the standard library covers everyday tasks.

# features.jts — sets and comprehension
primes = {2, 3, 5, 7, 11}
odds   = set([1, 3, 5, 7, 9])

print(primes & odds)   # {5, 7}
print(primes | odds)   # {1, 2, 3, 5, 7, 9, 11}
print(5 & 3)           # 1

Get Started

Up and running in seconds

One command. No build tools. No configuration.

1

Install Node.js

JTS GO installs through npm. If you don't have Node.js yet, install it from the official site.

Download Node.js
2

Install JTS GO

One global npm install gives you the compiler, the VM, and the toolchain.

npm install -g @jaytechsolutions/jts-go
3

Run your code

Create a .jts file and run it instantly.

jts hello.jts
Toolchain

Three commands, every stage

From source to bytecode to execution — all in your terminal.

jts

Compile and run a .jts file in one step

jtsc

Compile source to .jbc bytecode

jtsvm

Execute compiled bytecode directly

--update

Update to the latest version via npm
